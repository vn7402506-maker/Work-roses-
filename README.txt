WORK — розовая 3D-визитка

Как открыть:
1. Распакуйте архив.
2. Откройте файл index.html в браузере.
3. Для публикации загрузите все файлы из папки на любой статический хостинг.

Что внутри:
- адаптивная одностраничная визитка;
- розовая 3D-композиция с реакцией на движение мыши;
- плавные анимации и блоки «О нас», «Проекты», «Контакты»;
- мобильная версия.

Чтобы изменить контакт, откройте index.html и замените hello@work.studio на свой адрес.
Шрифты Google Fonts загружаются при наличии интернета.

Обновление: добавлен розовый блок вакансий с описанием легальных обязанностей, условий и официального оформления.
